## GitHub Pages 發布

1. 建立或開啟 GitHub repository。
2. 將本資料夾的所有檔案上傳至 `main` 分支的根目錄。`index.html` 不要包在另一層資料夾內。
3. 進入 **Settings → Pages**。
4. Source 選 **Deploy from a branch**；Branch 選 **main**，Folder 選 **/(root)**，按 **Save**。
5. 部署完成後，使用 Pages 顯示的網址播放簡報。

範例網址：`https://你的帳號.github.io/儲存庫名稱/`。

## 播放

- 左右方向鍵：換頁。
- F：全螢幕；N：講者提示。
- 目錄：跳頁；網址的 `#` 可直接指定某頁。
- 正文、附錄與 PROSPERO PDF 必須和 `index.html` 放在同一目錄，才能正常開啟。
